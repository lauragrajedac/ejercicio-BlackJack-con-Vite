# 🃏 Blackjack Game - Vite & Node.js

🇪🇸 Español

📖 Descripción del Proyecto

¡Bienvenido a este clásico juego de Blackjack desarrollado con JavaScript modular, empaquetado con Vite y con un diseño profesional de casino oscuro/dorado! 🎰✨ El objetivo del juego es sumar 21 puntos (o acercarse lo más posible sin pasarse) venciendo a la computadora. Cuenta con un sistema de ventanas modales personalizadas y frases divertidas al finalizar cada partida.

📂 Estructura del Proyecto

src/blackjack/: Contiene la arquitectura modular del juego.

index.js: Controlador principal de la lógica y eventos del DOM.

usecases/: Funciones independientes y reutilizables (crear baraja, pedir carta, valor de carta, turno de la computadora).

public/assets/cartas/: Carpeta de recursos con las imágenes PNG de todas las cartas de la baraja.

style.css: Estilos personalizados con estética de casino profesional (fieltro verde oscuro, detalles dorados y diseño responsivo).

vite.config.js: Configuración de Vite para el empaquetado y rutas relativas (BASE_URL).

🚀 Cómo correr el proyecto localmente

Sigue estos sencillos pasos para ejecutar el juego en tu computadora:

Clona el repositorio o abre la carpeta en tu terminal:

git clone https://github.com/tu-usuario/ejercicio-BlackJack-con-Vite.git
cd ejercicio-BlackJack-con-Vite

Instala las dependencias:

npm install

Inicia el servidor de desarrollo:

npm run dev

Abre el enlace local que aparece en tu terminal (usualmente http://localhost:ejemplo/) en tu navegador web preferido y ¡disfruta el juego! 🎮

🇬🇧 English

📖 Project Description

Welcome to this classic Blackjack game built with modular JavaScript, powered by Vite, and styled with a professional dark/gold casino aesthetic! 🎰✨ The goal is to reach 21 points (or get as close as possible without busting) while beating the computer. It features custom modal dialogs and entertaining personalized messages at the end of each round.

📂 Project Structure

src/blackjack/: Contains the modular architecture of the game.

index.js: Main game controller managing logic and DOM events.

usecases/: Independent, reusable functions (deck creation, card drawing, card valuation, computer turn).

public/assets/cartas/: Asset directory containing PNG images for all playing cards.

style.css: Custom styling with a professional casino aesthetic (dark green felt, gold accents, and responsive layout).

vite.config.js: Vite configuration for bundling and asset path resolution (BASE_URL).

🚀 How to run it locally

Follow these simple steps to run the game on your local machine:

Clone the repository or open the project folder in your terminal:

git clone https://github.com/tu-usuario/ejercicio-BlackJack-con-Vite.git
cd ejercicio-BlackJack-con-Vite

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local link provided in your terminal (usually http://localhost:example/) in your favorite web browser and enjoy the game! 🎮
